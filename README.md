# Профиль роли — пользовательский прототип

Интерактивный прототип работы с профилем роли: структура, создание и изменение профиля, согласование, индивидуальное и массовое подписание.

**Открыть:** https://tallercreator.github.io/profile-roli-prototype/

Сценарии доступны через кнопку «Сценарии». Перед запуском выберите участника и результат ожидания. Кнопка «Скопировать ссылку» создаёт прямую ссылку для CX с выбранной ролью и вариантом. Каждый запуск по ссылке начинает сценарий заново. Роль сохраняется на всём пути: на экране ожидания кликните в свободном месте, чтобы продолжить после действия другого человека. Кнопки, поля и вкладки сохраняют свои обычные действия. С клавиатуры ожидание можно продолжить Enter или пробелом, когда фокус находится на странице. Начальный экран — «Структура». Изменения в формах сохраняются только в браузере посетителя. Отчёты и PDF создаются локально, без отправки данных на сервер.

## Файлы

- `index.html` — интерфейс и логика прототипа.
- `assets/` — встроенные в исходный прототип изображения, иконки и шрифты.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

Сайт публикуется через GitHub Pages из корня ветки `main`. Чтобы обновить прототип, замените `index.html` и необходимые файлы в `assets/`.
